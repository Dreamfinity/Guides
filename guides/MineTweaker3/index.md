# Гайд по модификации MineTweaker3 (далее - MT)

Версия MT: 3.1.0 (https://github.com/Dreamfinity/MineTweaker3), по основному API не отличающаяся от 3.0.11

Версия ZenScript: 1.1.0 (https://github.com/Dreamfinity/ZenScript), по основному API не отличающаяся от 3.0.11

Данный гайд в основном касается самого мода MT, без привязки к нашим серверам. Однако в примерах используюся вставки из нашего кода

Что такое MineTweaker3? Это мод, позволяющий добавлять, удалять
