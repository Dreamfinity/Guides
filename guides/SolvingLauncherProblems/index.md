# Что делать, если не запускается лаунчер?

Внимательно прочитайте данный гайд и проблем не возникнет.
Обязательно убедитесь что используете компьютер с 64-битной ОС, а также установлена Java 64-bit.

В случае непонятных закрытий лаунчера – обязательно включите режим отладки в опциях лаунчера.
Если никакие из описанных решений вам не помогли – скопируйте вывод режима отладки в файл и отправьте нам
в сообщения группы [VK](https://vk.com/im/convo/-64518464) или [Telegram](https://t.me/dreamfinity?direct)

!!! info "Для пользователей Linux-систем"
    Убедитесь, что в вашей системе установлена Oracle JRE 8. Гайд по установке здесь: [https://losst.ru/ustanovka-java-v-linux](https://losst.ru/ustanovka-java-v-linux)

    Затем установите пакет JavaFX командой `sudo apt-get install openjfx`

Универсальный способ решения проблем с запуском

1. Удалите существующие версии Java JRE/JDK на вашем компьютере вот этой утилитой: [Скачать Java Uninstaller](https://www.java.com/ru/download/uninstalltool.jsp).
2. Перезагрузите компьютер.
3. Установите утилиту [CCleaner](https://www.ccleaner.com/ru-ru/ccleaner) – и очистите реестр.
4. Установите Java x64 по ссылке [Скачать Java 8 x64bit](https://javadl.oracle.com/webapps/download/AutoDL?BundleId=239858_230deb18db3e4014bb8e3e8324f81b43)
5. Запустите лаунчер.

<span class="problem-definition">Проблема</span>: У меня Linux. Не могу запустить лаунчер. В терминале ошибка `JavaFX API isn't available`

<span class="problem-solution">Решение</span>: У вас нет модуля JavaFX в системе. Что делать:

1. Убедитесь, что в вашей системе установлена Oracle JRE 8. Гайд по установке здесь: https://losst.ru/ustanovka-java-v-linux
2. Затем установите пакет JavaFX командой sudo apt-get install openjfx
3. Для надежности перезапустите систему.

---

<span class="problem-definition">Проблема</span>: Лаунчер не запускается при простом запуске. Нет ни окна, ни запущенного процесса в диспетчере задач.

<span class="problem-solution">Решение</span>: Скорее всего, ваша установленная Java сломана. Для решения этой проблемы:

1. Скачайте отладочный скрипт по ссылке: [https://dreamfinity.org/start.bat](https://dreamfinity.org/start.bat)
2. Запустите скрипт, проверьте запускается ли лаунчер теперь. Если лаунчер запустится после запуска с помощью скрипта,
то в таком случае вы можете пользоваться этим скриптом, но все равно нужно перейти к шагу 3.
3. Скачайте и установите официальную утилиту чистого удаления Java. [Скачать](https://www.java.com/ru/download/uninstalltool.jsp)
Запустите и выполните чистое удаление. Перезагрузите компьютер.
4. (Опционально, но важно) Очистите реестр своего компьютера утилитой CCleaner.

<span class="problem-definition">Проблема</span>: Лаунчер работает, но игра не запускается, и крашится при 30-70% загрузки Майнкрафта.

<span class="problem-solution">Решение</span>: Скорее всего не хватает памяти.

1. Убедитесь, что вы имеете х64-битную операционную систему, а так же (ВАЖНО!) Java 64-bit.
2. Убедитесь, что в настройках лаунчера выделено как минимум 1-2ГБ оперативной памяти.
3. НЕ ВЫДЕЛЯЙТЕ БОЛЕЕ 4ГБ ОПЕРАТИВНОЙ ПАМЯТИ! Это негативно может сказаться на общей работе компьютера.
Высокие значения выделенной памяти возможны только при наличии 16-32ГБ оперативной памяти в системе.

<span class="problem-definition">Проблема</span>: Лаунчер запускает игру, но она сразу же закрывается. В логе отладки видно ошибку `Exit code -98`

<span class="problem-solution">Решение</span>: Скорее всего, сломана ваша установленная Java. Необходима чистая переустановке (см. выше по гайду)

1. Кроме того, выставите ползунок выделенной памяти в положение 0 (Авто). Известно, что это помогает в решении
данной ошибки.

---

<span class="problem-definition">Проблема</span>: Лаунчер работает, но при запуске игры окно игры не появляется. В логе отладки нет ничего кроме Exit code (код ошибки).

<span class="problem-solution">Решение</span>: Возможно, проблема с вашими драйверами видеокарты.

1. Убедитесь, что вы используете последнюю версию видеодрайверов. Установите новую версию, если у вас старая.
2. Убедитесь, что вы принудительно запускаете лаунчер с использованием дискретной видеокарточки (если вы играете на ноутбуке).
3. Убедитесь, что не используете режим совместимости. Отключите его, если он активирован.
4. Запустите лаунчер от имени администратора.

---

<span class="problem-definition">Проблема</span>: Лаунчер работает, игра запускается, но крашится и вылетает в процессе игры. В краш-репорте есть сообщения об отказе видеодрайвера.

<span class="problem-solution">Решение</span>: Возможно, что-то не так с установленным игровым клиентом или видеодрайвером.

1. Убедитесь, что видеодрайвер установлен и актуален.
2. Переустановите клиент, удалив папки игровых клиентов, и скачав их заново.

---

<span class="problem-definition">Проблема</span>: Лаунчер запускается, но появляется окно `Connection refused: connect`

<span class="problem-solution">Решение</span>: Лаунчер не может соединиться с сервером авторизации. Проверьте настройки соединения

1. Подождите 3-5 минут и подключитесь заново. Возможно сервер авторизации на тех. работах.
2. Убедитесь что антивирус и фаерволл не блокируют исходящие подключения вашего компьютера.

---

<span class="problem-definition">Проблема</span>: Лаунчер запускается, но появляется окно `Java.net.SocketException: Software caused connection abort`

<span class="problem-solution">Решение</span>: Лаунчер не может соединиться с сервером авторизации, или сетевых подключений слишком много.

1. Подождите 3-5 минут, и подключитесь заново. Возможно сервер авторизации на тех. работах.
2. Убедитесь что антивирус и фаерволл не блокируют исходящие подключения вашего компьютера.
3. Отключите все лишние подключения к интернету. Оставьте только одно подключение – по проводу, или по Wi-Fi.
